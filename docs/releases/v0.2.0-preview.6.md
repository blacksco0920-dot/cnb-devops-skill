## 中文

这是面向早期使用者的预览版本。本文记录固定版本的范围；远端是否已发布以 [GitHub Releases](https://github.com/blacksco0920-dot/cnb-devops-skill/releases) 为准。

### 本版提供什么

- CNB → TCR → TAT 的测试部署、不可变候选、经批准的同镜像生产和隔离恢复流程。
- 可复用的项目生成、主机首装、云端配置、发布、恢复及验收收尾入口。
- 中英文使用首页、本地执行环境说明和已确认的来源代码 MIT 授权记录。

适用范围：PostgreSQL 16、可选 Redis 7、Ubuntu 24.04 / Linux amd64 目标服务器。管理端要求 Node.js 22、Python 3.12+ 和类 Unix 环境；恢复需本地 Unix socket Docker。当前完整实操主要来自 macOS/Codex。原生 Windows 不支持完整入口；Linux 桌面、WSL、远程开发环境及其他 AI 工具的端到端首接仍待验证。

### 已知限制

真实项目已经验证部署、生产晋级、业务、共存和声明范围内的恢复，详见[验证索引](../history/README.md)。这些结果不代表每个新入口的每种场景都已云端验证：

- 新 TCR 初始化器目前仅覆盖 Personal / ap-guangzhou；本版已对既有资源做真实只读验证，新建资源路径仍待实测。
- TAT 发布身份的 AccessKey 签发仍由 AI 按现有文档直接调用官方 API；必要的 CNB 令牌、Secret 页面保存、本人验证和生产审批仍需用户配合。
- 全新账号一次接通、外部新手独立使用和首次接入整体提速尚未验证，不承诺固定分钟数或 token 用量。
- 已安装控制器升级、数据恢复和复杂共享主机分别遵守对应流程；恢复只覆盖声明的数据，不等于整机或所有外部存储恢复。

### 安装与反馈

该版本在 GitHub 发布后，让 AI 按当前工具的方式安装固定 Tag `v0.2.0-preview.6`，记录解析后的完整提交和实际 Skill 位置。换版本时先查看差异；Skill 升级不授权覆盖已有主机程序或重新首装。未发布的本地准备版本不代表 GitHub 已提供下载。

本版 Skill 的版本号与随附运行包版本分别记录：运行包仍为 `0.2.0-preview.5`，可执行文件与本轮发布准备前一致，仅更新来源/依赖许可说明及相应清单摘要。既有主机无需因文档变化重新安装。

问题反馈沿[首页说明](../../README.md#试用反馈)，提供版本、环境、失败阶段和脱敏结果即可。

## English

This is a preview for early adopters. This page records its scope; [GitHub Releases](https://github.com/blacksco0920-dot/cnb-devops-skill/releases) determines whether it has been published remotely.

The release provides the CNB → TCR → TAT workflow for test deployments, immutable candidates, approved production promotion using the same images, and isolated recovery. It includes reusable setup and verification tools, Chinese and English READMEs, local environment requirements, and the source owner's confirmed MIT authorization.

The fixed deployment path targets PostgreSQL 16, optional Redis 7, and Ubuntu 24.04 / Linux amd64 servers. Local tools require Node.js 22, Python 3.12+, and a Unix-like environment; recovery also requires a local Docker daemon accessible through a Unix socket. End-to-end exercises have primarily used macOS and Codex. Native Windows is unsupported by the full local workflow; end-to-end onboarding on Linux desktops, WSL, remote development environments, and other AI tools remains unverified.

Real projects have exercised deployment, production promotion, business checks, coexistence, and recovery of declared data. See the [verification index](../history/README.md). Key preview limits:

- The new TCR initializer supports Personal / ap-guangzhou only. Live verification covered existing resources; fresh resource creation through this entry remains untested.
- TAT release AccessKey issuance still requires the AI to follow the documented API procedure. Required CNB token and Secret page operations, personal account verification, and production approvals still need the user.
- First-time setup with a new account, independent novice onboarding, and overall setup speed remain unverified. No fixed time or token budget is promised.
- Active controller upgrades, recovery, and complex shared hosts have their own procedures. Recovery covers declared data, not an entire host or every external store.

Once this version is published on GitHub, ask the AI to install the fixed tag `v0.2.0-preview.6`, record its resolved commit and Skill location, and review changes before updating. A local prepared version is not a remote release. Updating the Skill does not authorize overwriting an installed controller or repeating first installation.

The bundled runtime remains `0.2.0-preview.5`: executable files are unchanged by this release preparation; only provenance/dependency notices and their manifest hashes change. Existing hosts do not need reinstallation for these documentation changes.

Report issues using the [README guidance](../../README.en.md#preview-feedback), with the version, environment, failing stage, and redacted results.
