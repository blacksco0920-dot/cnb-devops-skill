# 陌生业务项目的独立测试接入

## 本轮验证范围

本轮把已有旧部署的 wxseo 接入一套独立测试环境，验证指定 Skill 能否适配陌生业务项目，并在已有两个项目的主机上追加第三个项目。固定 Skill 提交为 `7cb99d2aa06d18ca3bb589e0e4ee7e62ebb96da4`，运行包为 `0.2.0-preview.5`。

独立执行会话只取得冻结的 Skill、项目快照和本轮资源事实，完成业务适配与固定配置生成；协调会话负责资源准备、审查和云端验收。没有从旧项目复制部署实现，但复用了既有账号登录、受保护管理员连接和共享主机。这不是全新账号、空白主机或完全无人协助的首次使用测试。

应用为 Node.js / pnpm、API/Web、Prisma/PostgreSQL 16，并使用 COS 存储截图。源项目已有 8 项未提交改动，均纳入审核快照；原工作区、原分支、Git 公共配置和已有部署保持不变。独立仓库中的旧自动部署入口保留原字节归档并停用。

## 实际结果

| 环节 | 已验证结果 |
| --- | --- |
| 应用适配 | API/Web 构建身份、数据库真实就绪探针、空库初始迁移；本机目标架构镜像、重复迁移与业务检查通过 |
| 云资源 | 新 CNB 私有业务/Secret 仓库、TCR 命名空间及限定推送/只读身份、固定 TAT 命令及发布身份完成配置回读 |
| 共享首装 | 新项目独立网络、数据库、回环端口、运行输入及原生 Caddy 站点；既有域名解析直接复用 |
| Secret 交接 | AI 准备完整根级变量文件，用户在官方 Web 保存；真实测试流水线成功引用两文件 |
| Secret 引用限制 | 两个非授权分支分别引用 TCR/TAT 文件，均得到明确的 `allow_branches` 拒绝，脚本未执行 |
| 首轮流水线 | 项目校验、两个镜像构建推送、固定 TAT 部署、运行/公网验证、不可变 Tag 和 ready-last 回读均通过 |
| 业务及页面 | HTTPS 模拟登录、三行业规则报告、历史、分享及账号隔离通过；浏览器实际显示登录入口 |

| 数据库恢复 | 真实业务数据导出到本机，在不同 Docker daemon 隔离恢复；全表数据、schema、序列一致，源状态保持 |
| 共存 | 发布后和恢复后两次固定在线观测，已声明的旧容器、控制文件、入口和版本均保持；不代表持续负载或不可信租户隔离 |

本次未修改 Skill 运行程序来完成部署。CNB、TAT、首装、恢复及共存沿用固定入口；TCR 初始资源和凭据准备仍有项目外 API 编排。浏览器用于材料入口辅助及页面查看，没有代替 CI/TAT 执行部署。

完整业务、共存和恢复是候选生成后的独立验收，并非本轮 CI 创建候选前自动执行的全部检查。恢复包为 40,960 字节；其中用户/会话各 2 行、报告/分享各 3 行，连同其他表完成数据核对。恢复时只暂停新项目应用；受限 Docker 状态记录显示 Web 停止至启动约 34 秒、API 约 4 秒，这不是连续外部可用性监测所得的精确停机时长。

## 效率与仍需固化的部分

首轮真实流水线耗时 **186.618 秒，约 3.11 分钟**，没有失败重试。真实 HTTPS 业务脚本约 5.3 秒完成；恢复和共存另计。

首次项目观察完成于 09:25:18 UTC，真实流水线开始于 11:49:50 UTC，中间约 **144.5 分钟**包含陌生项目适配、云资源准备、审查、用户等待和协调。首次读取起点、各类等待与总 token 未可靠分离采集。不能用流水线耗时宣称整个首次接入只需 3 分钟，也不能据此给出相对上一项目的提效比例。

后续优先收敛实际出现的工作，避免继续扩展测试数量：

1. **TCR 初始化固定入口。** 把命名空间、限定身份、登录凭据和未知结果续接固化；本轮仍需临时 API 编排，收益尚未量化。
2. **明确执行者的源码起点。** 新 worktree 默认落到较旧提交，产生额外导入/对齐；交接时应直接绑定当前源码和未提交改动的审核快照。
3. **补齐测试环境收尾。** 现有固定收尾只接纳生产回查，测试不能伪装为生产回执。本轮依据真实证据整理既有项目文档；后续应提供测试候选/TAT 回查和状态同步入口。
4. **补充 Git helper 的已知前提。** CNB 官方 helper 要求目标 host 出现在 remote 配置中；本轮单命令映射解决，未改共享 Git 配置，无需新登录体系。
5. **适配交付时检查数据库就绪。** 执行者初次遗漏计划中的真实数据库探针，复核后补齐。应把依赖故障时正确返回不可用纳入交付检查。

本机代理曾影响本地下载和容器内转发；隔离覆盖解决。本轮真实 CNB 使用原项目的国内镜像源正常完成，不能把本机代理问题归因于 CNB 或镜像源。

## 验收边界与证据

本轮仅测试环境，生产未启用。短信为原有模拟验证码，AI 使用规则兜底，未调用真实短信或付费模型。浏览器验证限于登录入口呈现，完整业务主要通过真实 HTTP 验收。

COS 复用同一所有者的现有凭据并使用新测试前缀；未证明凭据在权限层只能访问此前缀。对象当前读写通过，**对象版本、备份和恢复尚未验证**。数据库恢复只覆盖 PostgreSQL，业务挂载为空，不覆盖 COS、运行秘密或整机。合成账号、报告及图片保留供复核，精确资源范围记录在私密清单中。

原始回执、源码快照、固定工件、命令日志和完整资源索引保存在仓库外私密目录，项目的既有状态文档指向该索引。公开记录只保留身份和摘要，不包含凭据、数据库内容、手机号或签名 URL。
