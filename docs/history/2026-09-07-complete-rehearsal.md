## 本轮修复

- Ubuntu Caddy 2.6.2 使用 `/dev/stdin` 读取配置，修正初装兼容问题；仅管理员 helper 变化时提供显式续接，保留已接受的安装回执和运行文件。
- 生成的生产就绪按钮补齐官方 schema 要求的描述；生产事件使用完整键 `tag_deploy.production`。旧候选事件初始化失败后，重新走测试生成新候选，没有修改旧 Tag 或绕过流水线发布。
- 验收检查各个必需阶段。CNB 的 `breakIfModify` 可在跳过发布与候选后仍返回总状态 success，这类构建不算部署成功。
- 输入参考补齐 SSH/APT、生产签名、导出下载与离机恢复命令；独立恢复时补清实际安装锁与当前生成锁的区别。
