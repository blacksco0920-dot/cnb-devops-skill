# FinAgent 完整部署与最多五轮实操

**目标：**延续已批准的可复用包方案，使用 FinAgent 完成最多五轮重置、完整部署、复盘优化；验收不能缩成测试发布。

**架构：**保留同一仓库、同一 Compose 发布核心和 CNB → TCR → TAT 流程。生产只晋级测试候选的同一组 digest；管理员侧签名批准，CI 转发，主机固定公钥验证。恢复由包内导出及本机隔离恢复入口完成，不引入控制仓库或常驻服务。

**技术栈：**现有 Python、Node.js、Bash、Git、Docker、腾讯云 SDK；Ubuntu 24.04、PostgreSQL 16。沿用锁定依赖。

## 全局约束

- 用户已授权本目标必要配置与最多五轮重置；只作用于核对过的 FinAgent 演练仓库和 test01/test02。其他项目、主机和本地原始工作区不在重置范围。
- 每轮重置前保存本轮证据及需要保留的数据，确认实际资源身份。平台实名或验证码需要本人时按实际阻塞报告，已有授权不重复询问。
- 构建、测试、候选、审批、生产、业务、恢复分别核验；生产不重建镜像。签名私钥不进入 CNB 或主机，运行秘密不进入普通仓库、TAT 正文或日志。
- 每个环境有独立路径、数据库、网络、策略和命令；根发布脚本拒绝未经生产授权入口的生产请求。
- 快速路径只需 Skill、项目配置、必要业务适配及账号输入；不得依赖旧会话、ecat 工作区或未随包交付的临时脚本。
- 最多五轮真实重置，修复重试保留在该轮。连续两轮无需改公共核心的完整成功作为稳定性证据；若达到第五轮仍有实质缺口，按未完成报告，不能修改验收定义。
- 逐项记录墙钟耗时、平台运行时间、人为等待和实际人工介入；没有工具证据的 token 数不估造。效率目标为账号输入齐备后的一轮自动部署和恢复在 30 分钟内，人工身份验证等待另列。

## 任务与接口

- [ ] **生产共同核心。** `host/tat-deploy-test.py`、`ci/release-request.mjs`、安装/bootstrap/Caddy 支持固定 test/production 策略及独立作用域；默认测试行为兼容。以环境交叉请求、路径隔离和未经批准生产请求被拒绝的用例验证。
- [ ] **生产授权与执行。** 新增包内管理员签名、CI 候选/就绪/批准转发和主机验证入口；复用现有 TAT 的正文、目标、调用与回执核验。绑定候选、目标策略、控制程序、期限及单次状态，验证过期、重放、漂移和迁移中断。来源复用此前 FinAgent 授权/验签实现；精确输入由实现接口记录，不复制旧控制仓库。
- [ ] **业务恢复。** `host/recover-project.py` 与 `recovery-policy.json`：export/resume-source/restore-local。保持发布锁，精确暂停并恢复原应用容器；PostgreSQL 全表、schema、序列及声明业务目录对账。恢复在不同 Docker daemon 的全新隔离目标真实执行；空库 archive 可读不是业务恢复。缓存和其他未覆盖存储明确分类。
- [ ] **一次配置生成。** `project.schema.json`、`templates/render.py`、`scripts/prepare-project.py` 生成两环境完整固定工件、恢复策略及可执行生产事件；测试候选生成沿用现有阶段。使用独立环境工件锁，所有云 ID 和凭据留私密输入。执行生成、Compose 与真实调用接口检查，禁用占位不得混入已启用事件。
- [ ] **固定接入与升级。** 提供可复用的授权管理员安装、核验、升级和传输入口；普通 shell/SSH/SDK 可运行，浏览器仅用于平台必需的人为步骤。准备阶段明确缺少的权限与通道，一次配置后重复轮次不重新现场设计。
- [ ] **最多五轮。** 核对/备份 → 真实重置 → 计时接入 → 同提交 CI → 测试业务 → 自动候选 → 有效批准 → 同摘要生产 → 生产业务 → 离机恢复 → 复盘最小修复。至少后一轮由独立子智能体仅凭 Skill 与必要项目输入接入，收集它实际需要补问或补写的内容。
- [ ] **交付审核。** 按上述约束逐项查真实证据；收敛 README/标准工作流/接入文档，更新版本与验证范围，清理本次临时权限。保留每轮不可变证据与未解决问题，最终结论不得由本地测试数量替代。
